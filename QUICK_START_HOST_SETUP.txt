REQUIRED STEPS (Run as Administrator):
================================================================================

STEP 1: Configure Windows Firewall
-----------------------------------
Right-click PowerShell or Command Prompt → "Run as administrator", then run:

    netsh advfirewall firewall add rule name="MySQL" dir=in action=allow protocol=TCP localport=3306

OR use the automated script:
    Right-click "setup_mysql_host.bat" → "Run as administrator"


STEP 2: Create Remote Database User
------------------------------------
Open Command Prompt and run:

    mysql -u root -p

Enter your MySQL root password, then paste:

    CREATE USER 'attendance_user'@'%' IDENTIFIED BY 'attendance_secure_pass_2024!';
    GRANT ALL PRIVILEGES ON attendance_db.* TO 'attendance_user'@'%';
    FLUSH PRIVILEGES;
    EXIT;

OR use the SQL script:
    mysql -u root -p < setup_mysql_remote_user.sql


STEP 3: Verify Database Exists
------------------------------
If attendance_db doesn't exist yet, create it:

    mysql -u root -p

Then:
    CREATE DATABASE IF NOT EXISTS attendance_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    EXIT;


STEP 4: Test Connection
-----------------------
From this computer:
    mysql -u root -p -h 127.0.0.1 attendance_db

From remote computer (after setup):
    mysql -h 192.168.50.108 -u attendance_user -p attendance_db


CONFIGURATION FOR REMOTE COMPUTER:
================================================================================
On the remote computer, set these environment variables:

    DB_HOST=192.168.50.108
    DB_NAME=attendance_db
    DB_USER=attendance_user
    DB_PASSWORD=attendance_secure_pass_2024!
    DB_PORT=3306

Or update Django settings.py:
    'HOST': '192.168.50.108',  # This computer's IP address
